# AI Soil Analysis System

A Streamlit-based application that analyzes soil properties using pH, moisture, density, and organic content, and generates AI-powered recommendations using LLaMA3.

## Features
- Soil strength classification
- Construction suitability prediction
- Agricultural suitability assessment
- AI-generated soil reports using LLaMA3
- CSV report storage

## Technologies Used
- Python
- Streamlit
- Pandas
- Requests
- Ollama (LLaMA3)
